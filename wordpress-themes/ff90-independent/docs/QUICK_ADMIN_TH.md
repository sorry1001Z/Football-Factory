# คู่มือแก้ไข FF90 แบบไม่ต้องเขียนโค้ด

## แบนเนอร์ขายโฆษณา 3 จุด

ไปที่ **รูปลักษณ์ → ปรับแต่ง → FF90 Banner Sale**

- ข้างโลโก้: รูปแนะนำ 468×60 px
- คั่นกลุ่มข่าว จุดที่ 1: รูปแนะนำ 970×120 px
- คั่นกลุ่มข่าว จุดที่ 2: รูปแนะนำ 970×120 px

กดเลือกรูป → อัปโหลดหรือเลือกจากคลังสื่อ → ใส่ลิงก์ปลายทางถ้ามี → กด
**Publish** แต่ละจุดแก้แยกกันได้ ลบรูปเพื่อกลับเป็นพื้นที่ว่างสำหรับขายโฆษณา
หากไม่ต้องการให้เห็นพื้นที่ว่าง ให้ปิดตัวเลือกแสดงพื้นที่ขาย รูปไม่ถูกครอป
บนมือถือ และจะแสดงคำว่า “โฆษณา” เสมอ

## ติดต่อเราและโซเชียล

ไปที่ **FF90 Contact & Social** เลือกหน้า “ติดต่อเรา” และใส่อีเมล
**rom2001th@gmail.com** เมนูจะเพิ่มลิงก์หน้าติดต่อโดยไม่เพิ่มซ้ำ

Facebook, YouTube และ TikTok แสดงไอคอนไว้ก่อน ไม่สามารถคลิกได้จนกว่าจะใส่
URL จริง หากมี URL ภายหลัง ให้กรอกในช่องของแพลตฟอร์มแล้ว Publish

## ป้ายข่าว

- **NEW:** ข่าวเผยแพร่ยังไม่ครบ 3 ชั่วโมง
- **HOT:** ข่าวยอดเข้าชมสูงสุด 5 อันดับของวัน
- **BEST:** ข่าวยอดเข้าชมสูงสุด 5 อันดับของสัปดาห์ เริ่มวันจันทร์

เปิดใช้ปลั๊กอิน **FF90 News Insights** แยกจากธีมเพื่อเก็บและจัดอันดับยอดดู
สถิติเริ่มเก็บหลังเปิดใช้ ไม่มีการสร้างยอดเก่าย้อนหลัง การรีเฟรชจากเบราว์เซอร์
เดิมในวันเดียวกันไม่เพิ่มซ้ำให้ข่าวเดียวกัน และไม่ใช่การนับ “คน” แบบยืนยันตัวตน
หากใช้ cache เต็มหน้าหรือทำแอปในอนาคต ต้องต่อข้อมูล Analytics ให้ครอบคลุม
ก่อนอ้างว่านับทุกช่องทางครบ

ของรายการเมนูตามคู่มือ EDITORIAL_FEATURES.md การเปลี่ยนชื่อเมนูไม่เปลี่ยน URL ข่าว
