== Description ==
Original standalone Thai football news theme. Two homepage layouts selected in
Appearance > Customize > FF90 Homepage Layout. No parent theme or paid assets.

== Installation ==
Upload ff90-independent.zip in Appearance > Themes > Add New > Upload Theme.
Activate; assign Primary and Footer menus; publish native WordPress posts with
featured images. Choose Main V2 or ColorMag 01 in the Customizer and Publish.
Football/SEO/analytics integrations are optional and owned by plugins.
