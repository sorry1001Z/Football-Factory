FF90 installation packages

Theme: ff90-independent 1.2.0
Plugins: 15 individual installable ZIPs inside ff90-all-15-plugins.zip.
Extract the outer bundle first. Upload the theme ZIP via Appearance > Themes.
Extract the plugin collection and upload each plugin ZIP via Plugins > Add New.
Use an isolated staging site first. Production readiness is not certified.
Database, uploaded articles, private API credentials, OAuth tokens, and WordPress admin credentials are not included.
Configure your own external service connections after installation.
Content automation is not a completed live publisher.
