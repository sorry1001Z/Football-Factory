# Football Factory

Initial staging placeholder and WordPress theme package for the Football Factory project.

This repository is prepared with a minimal static page so Vercel can import and deploy the `main` branch successfully.

The WordPress theme package is included in `football-factory/`. Install that folder as a theme in WordPress, or zip that folder when uploading through the WordPress admin theme installer.

The companion WordPress plugin is included in `wordpress-plugins/football-factory-core/`. Install and activate it in WordPress to enable Football Factory CPTs, REST endpoints, SEO schema output, and integration settings. The plugin includes empty settings fields only; no API keys or secrets are committed.
