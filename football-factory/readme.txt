Football Factory — a Thai football news, data, and AI-driven analysis theme.

== Description ==

Football Factory is a Hybrid Classic PHP theme that mirrors the approved
Enterprise Frontend v1.0 visual baseline. It is the WordPress Theme for the
Football Factory site; live football data is provided by the Football Factory
Core Plugin (separate plugin).

The theme:

* Is a Hybrid Theme (Classic PHP for all 12 page types).
* Uses `theme.json` v2 for design tokens, no FSE block templates.
* Ships with the approved CSS / JS / sprite / favicon assets.
* Is activation-safe: activates and renders even when the Core Plugin is absent.
* Targets WCAG 2.1 AA accessibility.
* Has no third-party dependencies, no CDN, no external trackers.

The current release (0.1.0) is a Phase 6B scaffold. Visual parity with the
approved frontend is not yet claimed.
