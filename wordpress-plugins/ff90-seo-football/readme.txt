=== FF90 SEO Football Adapter ===
Requires at least: 6.5
Requires PHP: 7.4
Requires Plugins: ff90-seo
Stable tag: 0.1.0
License: GPLv3 or later

Optional domain adapter for FF90 Modular SEO 0.2.0+. Activate base SEO first.
Static V3 identity seed and weighted Thai/English intent rules. Registry is not live sports data or a guarantee of current-season membership.
Map a real Category/Tag public archive using its Football identity field and verify the mapping. Unmapped/ambiguous identities never create invented routes.
Provides entities, explicit static relationships, intent and advisory SportsOrganization/Organization candidates. Player/Match schemas remain refused without authoritative data.
No external API, automatic public entity schema insertion, news editing, or theme dependency.
Override registry through ff90_seo_football_registry; replace the domain adapter through ff90_seo_domain_adapter.
