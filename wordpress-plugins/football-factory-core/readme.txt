Core football data, REST API, SEO schema, and integration scaffolding for the Football Factory WordPress theme.

== Description ==

Football Factory Core is the companion plugin expected by the Football Factory theme.

It provides:

* Football content types for matches, teams, players, leagues, and transfers.
* Football taxonomies for seasons and competitions.
* Public REST status and match endpoints.
* A protected n8n event endpoint.
* Basic SEO JSON-LD output.
* A settings page for future Football API and n8n credentials.

No API keys, secrets, or production credentials are included.

== Installation ==

Upload the `football-factory-core` folder as a WordPress plugin, or zip the folder and upload it through Plugins > Add New > Upload Plugin.

Activate Football Factory Core before testing live football data screens in the Football Factory theme.
