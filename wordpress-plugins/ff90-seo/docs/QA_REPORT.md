Initial browser attempts exposed a sandbox static-file/realpath-cache issue
when serving a plugin symlink; installed the actual ZIP and restarted only our

The optional gate was checked for final stored post status on ordinary writes,
meta mutations and wp_publish_post. It is NOT a transactional security boundary;
trusted plugin hooks can see intermediate publish transitions. Human approval,
rights gates, kill switch and automation must remain separate and authoritative.
